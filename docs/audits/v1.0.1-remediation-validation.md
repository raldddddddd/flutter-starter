**Scope:** `main` at `dfc75a3` ("fix: remediate v1.0.0 audit findings"), checked against `docs/audits/v1.0.0-engineering-audit.md`. This was a read-only review. No repository files were modified. The race probes ran in a separate scratch clone, which was deleted afterwards.

## Verdict

**Ready to tag `v1.0.1`.** All nine findings (C1–C3, I1–I6) are resolved, and each one has a regression test. I found no release-blocking regression. ### R1 (low, latent, not blocking): a `restore()` overlapping a pending `establishSession` at the same epoch
**Where:** `session_manager.dart:117-157` together with `:89-113`.

`establishSession` advances the epoch and then sets `restoring` with `_refreshToken = null`. A `restore()` that starts after that point captures the *same* epoch, reads the not-yet-written envelope as missing, and queues `_clearUserScope(null)` behind the login. When it runs, it wipes the new account's scope and publishes `unauthenticated` over the new `authenticatedOnline`. That leaves a live access token in memory and a stored envelope, so the next cold start silently restores the account.

**Probe P6 output:** `unauthenticated/null/e1 access=b env={session.envelope: {"accountId":"bob","refreshToken":"rb"}}`

**Why it does not block v1:** the only `restore()` callers are the one-shot keep-alive `sessionRestorationProvider`, which completes before `/login` is reachable, and the resume listener, which fires only in `authenticatedOffline`. `establishSession` switches the status to `restoring` synchronously, so the resume listener never takes the envelope-read path during a login. The only `establishSession` caller is the dev demo button on `/login`.

**Smallest fix (optional follow-up):** in `restore()`, skip the envelope-read path while a login is pending. For example, have `establishSession` set a `_establishing` epoch and have `restore()` return when `_establishing == _snapshot.epoch`, or have `establishSession` advance the epoch again right before publishing so the queued clear sees a stale epoch. Add a probe-style test like P6.
